#Calculadora Simples 

Uma calculadora web moderna, leve e responsiva, desenvolvida com HTML5, CSS3 e JavaScript puro. Este projeto foi criado com foco em praticidade, código limpo e uma ótima experiência de usuário para operações matemáticas básicas.

#Funcionalidades:

Este projeto executa operações básicas de adição, subtração, multiplicação e divisão. Possui uma interface limpa com design minimalista inspirado em calculadoras modernas, além de ser totalmente responsivo para diferentes tamanhos de tela. Conta também com recursos de limpeza rápida para reiniciar o display completo ou apagar o último dígito inserido.
Tecnologias Utilizadas

O desenvolvimento utilizou HTML5 para a estruturação semântica da interface, CSS3 para a estilização moderna com uso de Flexbox e variáveis visuais, e JavaScript moderno (ES6+) para toda a lógica de cálculo, manipulação do DOM e tratamento de eventos dos botões.
